# 🐍 100 Days of Python Challenge

Welcome to my **100 Days of Python Challenge**! 🚀  

This is my **self-taught journey** to learn Python, where I commit to coding **every day** for 100 days.  
I'll be documenting my progress, challenges, and lessons learned along the way.  

---

## 📌 About This Challenge
- 📖 **Goal**: Improve my Python skills through daily coding.
- 🏗 **Approach**: Hands-on coding, solving problems, and building small projects.
- 🔄 **Tracking**: Each day's progress will be logged in this repository.

---

## 🛠 Topics Covered
Throughout the challenge, I'll be covering topics like:

- ✅ Data Structures & Algorithms
